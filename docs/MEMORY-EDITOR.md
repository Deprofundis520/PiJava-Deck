# PiJava Deck v3.13 内存修改使用说明

## 启动与入口

完整解压 v3.13，运行“一键安装”更新，确认游戏列表显示 v3.13。游戏中按右侧 **≡ → 内存修改 → A**。进入工具会暂停 Java 游戏；方向操作使用左摇杆或十字键，无需键盘。

本版支持 **8、16、32、64 位有符号整数**。默认 32 位，适合先尝试金币、血量、道具数量。浮点、原始进程地址、任意字节补丁和跨启动金手指配置没有开放。

## 示例：将金币改为 9999

1. 先在游戏内正常保存进度，记下当前金币，例如 100。
2. ≡ → 内存修改，左侧选“新搜索数值”，按 A。
3. 输入 100，按 ≡ 或点“完成”。等待搜索结束。
4. 按左侧 **视图键** 返回游戏，消费金币，使它变为 90。
5. 再按 ≡ → 内存修改，选“再次搜索数值”，输入 90；也可选“筛选：数值减少”。
6. 如果结果仍多，返回游戏继续改变数值，再次筛选。
7. 左侧选“查看搜索结果”按 A，或按右进入结果面板。上下选中目标，按 A 输入 9999，再按 ≡ 确认。
8. 返回结果页后按 **X** 可锁定该目标的当前值。按视图键继续游戏。

不会自动同时修改所有搜索结果。请先缩小范围，再检查单个目标。结果名是 Java 类/字段或数组下标；混淆后的游戏可能只有 a、b 等名字，无法直接标注“金币”。

## 搜索与筛选

| 项目 | 作用 |
|---|---|
| 类型 | A 或左右切换 32、16、8、64 位整数；仅决定下一次新搜索的类型，不改变已有结果类型 |
| 新搜索数值 | 开始一轮精确值搜索，完成后替换旧结果 |
| 未知初值搜索 | 不输入数值，记录所选类型的初始值；游戏改变后再用变化条件筛选 |
| 再次搜索数值 | 从已有结果中保留等于输入值的目标 |
| 增加 / 减少 | 与上次成功搜索的数值比较 |
| 变化 / 未变化 | 与上次成功搜索的数值比较 |
| 查看搜索结果 | 进入右侧结果列表，L1/R1 每次翻 8 项 |

搜索的是游戏 JAR 类中可修改的整数实例字段、已初始化的静态字段，以及堆中的相应基本类型数组。系统字段、引用、final 字段和常量不开放；数组元素仍可搜索，即使保存数组引用的字段为 final。

每次筛选成功后更新比较基线。搜索期间游戏保持暂停，按 B 取消并保留上次结果；≡ 取消搜索并返回暂停菜单，视图键取消搜索后继续游戏。数值变化需返回游戏后发生。

搜索按批次执行，候选上限 10 万项。超过上限会取消本次搜索并提示，不发布截断的部分结果；可改用具体数值或其他类型。未知初值更容易达到上限。

## 数值输入

| 操作 | 按键 |
|---|---|
| 选择屏幕数字，输入 | 左摇杆 / 十字键，A |
| 退格 | X |
| 切换正负号 | Y |
| 移动光标 | L1 / R1 |
| 清空输入 | 视图键 |
| 确认数值 | ≡，或点击“完成” |
| 取消输入 | B |

修改目标时会预选原值，输入新数字即可替换。也支持外接键盘、系统键盘和粘贴；请输入十进制整数，不含空格、千位逗号或小数点。

| 类型 | 合法范围 |
|---|---|
| 8 位 | -128 ～ 127 |
| 16 位 | -32768 ～ 32767 |
| 32 位 | -2147483648 ～ 2147483647 |
| 64 位 | -9223372036854775808 ～ 9223372036854775807 |

输入超出范围会显示错误并保留输入框，不写入游戏，也不会静默截断。

## 锁定、撤销与退出

- **结果面板 X**：将当前值加入锁定，已有条目则切换启用/暂停。修改已锁定目标时，锁定值也随之更新。
- **结果面板 Y**：切换所有锁定的总开关；条目保留，可再次开启。
- **管理锁定列表**：显示当前值、目标锁定值和启用状态。A 修改目标值，X 单独启停，Y 删除当前锁定。删除只移除规则，不恢复游戏数值。
- **撤销上次修改**：最多记录最近 32 次手动改值。仅当目标仍有效且当前值等于上次写入值时恢复原值，并删除该目标的锁定；游戏已产生新数值时拒绝覆盖。
- **清空结果和锁定**：清除搜索、规则和撤销记录，不恢复或重写已经修改的游戏值。
- **B**：右侧返回左侧；左侧返回暂停菜单。**≡**：直接回暂停菜单。**视图键**：继续游戏，保留当前搜索和规则。

最多 64 条锁定。锁定在未暂停且有焦点的游戏工作片段前后重写数值；在工具界面不推进游戏。它不拦截每条 Java 指令，不能保证阻止一个片段内的死亡、扣费或其他副作用，也不会重写 Java 局部变量/操作数栈。

## 存档与生效范围

搜索、锁定和撤销只在当前运行中保留。读即时存档、重新开始、换游戏或结束游戏后会清除；对象被 GC 回收或其槽位复用后拒绝旧目标，失效锁定会被移除。

手动修改的普通 Java 数值可以随即时存档保存；锁定规则不存入即时存档。游戏自己的 RMS 保存是否保留修改，取决于游戏的保存、校验或重算方式。已用 v3.12 冻结源码生成状态，再由 v3.13 源码读取并继续执行进行验证，但不保证所有游戏和更早版本的即时存档均兼容。

加密/异或数值、计算后显示值、仅存在于局部变量的值、字节数组里打包的多字节数值、不可修改的 final 字段，可能无法用本工具直接定位。没有提供 float/double 搜索。

## 验证范围

已执行生产内存模块与面板的 VM 综合测试、相关输入/菜单/游戏目录/即时存档管理回归、v3.12 → v3.13 状态往返，以及 Linux x86_64 编译和发布包检查。新探针包含类型范围、继承、静态/数组写入、搜索取消/上限、锁定/撤销、GC/代际、读档、缓存屏障及真实中文界面渲染。

主机测试在 Windows 适配层运行解释器/fast 路径；JIT 读取 helper 有检查，未执行 Linux JIT 机器码。未运行发布的 Linux ELF、Deck 实机、Steam Input 实际硬件或商业游戏场景；没有性能提升承诺。
